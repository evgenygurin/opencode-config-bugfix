# Brainstorming

Generate ideas, explore approaches, and evaluate alternatives before writing code.

1. Define the problem clearly.
2. Generate at least 3 possible approaches.
3. Evaluate each approach for feasibility, simplicity, and impact.
4. Select the best approach and outline the implementation.
5. Document assumptions and constraints.

## Dependencies

- No external dependencies. This skill is built into OpenCode.
- Requires: OpenCode runtime with `compatibility: opencode`.

Do not modify files during brainstorming unless explicitly requested.
